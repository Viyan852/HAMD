# Hamd

**Hamd** is a custom typeface featuring a distinctive set of letterforms, digits, and glyphs designed for creative typography and digital use.

## Font

The font is provided in TrueType (`.ttf`) format.

### Included

* Custom letterforms
* Custom numerals
* Extended glyph set
* OpenType font format
* Ready for use in compatible design and typography software

## Installation

### Windows

1. Download the `.otf` font from the `fonts` folder.
2. Right-click the font file.
3. Select **Install**.

### macOS

1. Download the `.otf` font.
2. Double-click the file.
3. Open it with Font Book.
4. Select **Install Font**.

## Usage

After installation, select **Hamd** from your application's font list.

The font can be used in applications that support OpenType fonts.
